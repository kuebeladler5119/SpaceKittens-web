# Space Kittens – Browser-Testbuild (Friends Beta)

Statischer Build des Spiels für einen kleinen Freundetest im Handy-Browser – **kein offizieller Release**.
Quellcode: privates Repository. Hier liegt nur der fertige Web-Build.

- Spielen: https://kuebeladler5119.github.io/SpaceKittens-web/
- Der Spielstand wird nur lokal im Browser gespeichert (jedes Handy/jeder Browser hat einen eigenen).
- Keine Käufe, keine Werbung. Feedback: Einstellungen → „Beta-Feedback senden“.
- Die Seite ist für Suchmaschinen auf `noindex` gestellt, aber öffentlich: Wer den Link hat, kann sie öffnen.
